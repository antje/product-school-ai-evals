## Method + Ground Truth (two ✅/⚠️ cells)

### Hallucination Rate
- **Method:** The Module 3 grounding judge (`claude-opus-5`, calibrated at κ 0.824) splits each summary into factual claims and flags any claim with no supporting span in the source report; a human confirms every flag, and a code check compares every number against the report. Rated ⚠️ because the judge was calibrated on Ascend IQ answers, not research-report summaries; recalibrating it on 30 human-labelled summaries to κ ≥ 0.6 turns this cell ✅.
- **Ground truth:** The confidential research report the summary was generated from, frozen at generation time.

### Latency
- **Method:** Server-side timing on every request, P95 from request received to summary delivered, tracked per release.
- **Ground truth:** The delivery SLA. Summaries go out by email and web rather than in a live chat, so the SLA is measured in minutes rather than seconds, which is why plain telemetry is enough for ✅.

## Strategic acceptance

**Accepted gap:** Toxicity (UX Trust)

Summaries paraphrase professional research written by our own analysts, and no user text shapes the output, so offensive language has no plausible path in. Building a toxicity classifier now would spend eval effort on the least likely failure in this product. Kill criterion: we close this gap if any client reports offensive or inappropriate language in a summary, or if source reports start quoting user-generated content (social posts, forum threads, review text) verbatim, since that is the first real path for toxic language to enter. Revisited at the Jan 15, 2027 portfolio review regardless.

## Critical mitigation

**Critical gap:** Drift Monitoring (Robustness)

**Why critical:** Summaries go straight to $50k+ clients by email, with no human in between and no way to recall a sent email. New sectors and report templates arrive every quarter, and the grounding judge only runs offline on a fixed set, so a hallucination rate that creeps up on new report types reaches clients unseen. Drift ranks above bias, the other open gap, because it compounds our P0 failure class; bias goes into the Q1 quarterly human audit.

**Mitigation plan:** Instrument every summary as a trace with its source-report ID. Each week, score a sample of at least 50 summaries with the grounding judge, oversampling new sectors and report templates. Alert when two consecutive weekly samples run above the offline unsupported-claim baseline, or when the mix of sectors and templates shifts away from the reference distribution. Flagged summaries are clustered weekly and the worst join the offline regression set. Owner: the Group PM owns the thresholds and the weekly review; the ML engineering lead owns the pipeline. Live by Nov 13, 2026, six weeks out, so it runs before Q4 renewal conversations.
